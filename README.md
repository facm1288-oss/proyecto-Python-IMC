# Calculadora de índice masa corporal (IMC)
Este es un programa en Python desarrollado para calcular el Índice de masa corporal (IMC) a partir de los datos igrsados por el usuario
## Requisitos 
-Python 3.x
## Funcionalidades
solicita edad, peso (KG) y altura (m) mediante consola 
realiza el calculo del (IMC) aplicando la formula matemática: peso / (estatura ^2)
muestra el resultado formateado a dos decimales
